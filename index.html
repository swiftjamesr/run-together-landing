Run Together

Just because you aren't together doesn't mean you're not gonna wanna run together.

Run Together is a personal, non-commercial software project: a cross-platform (iOS + Android) Flutter app for live GPS run tracking, paired with a Node.js/TypeScript relay server for real-time position and stats sharing between two runners who are apart. It started as a rewrite of a few earlier, messier attempts at the same idea into a single shared codebase.

What it does

  • Tracks a run's live GPS route, distance, pace, and elevation.
  • Lets a friend pair into your run over a lightweight WebSocket relay, so you can see each other's live position and stats side by side even when you're running in two different places.
  • Records history: saved routes, pace/elevation charts, personal-record and milestone badges, and replay/ghost-racing against a past run.
  • Friends, an activity feed, and photo/video sharing on saved runs.

How it's built

The mobile app is written in Flutter/Dart. The backend is a small Node.js/TypeScript relay server (Express + a plain WebSocket protocol for live pairing), backed by DynamoDB for accounts/friends/activity data and S3 for media, deployed on Render.

Status

This is a hobby project, built and maintained by one person for personal use with friends and family - not a commercial product, and not monetized in any way.
